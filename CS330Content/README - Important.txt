Important for running the project successfully:

Before running the project, unzip the libraries zip file in the same folder as this README file. 
Use the "Extract here" option in WinRAR to ensure the libraries folder is in the same directory 
as this file.

If you use the default Windows extractor, it will create a nested "libraries" folder, 
which will prevent the project from running. If you prefer to use the default extractor, 
make sure to move the "libraries" folder to the current directory where this README file 
is located for the project to work properly.

(The libraries folder was compressed into a zip file for easier upload.)
